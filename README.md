# 🖼️ CNN for CIFAR-10 Image Classification

A Convolutional Neural Network (CNN) built to classify images from the CIFAR-10 dataset, implemented in a Jupyter Notebook.

## Dataset

[CIFAR-10](https://www.cs.toronto.edu/~kriz/cifar.html): 60,000 color images (32×32) in 10 classes, with 50,000 for training and 10,000 for testing.

Classes: airplane, automobile, bird, cat, deer, dog, frog, horse, ship, truck.
